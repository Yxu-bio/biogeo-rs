# BioGeoBEARS-like Rust CLI v0.1 任务书

更新日期：2026-08-27

## 一、项目目标

交付一个可独立运行、可由新版 RASP 作为子进程调用的高性能生物地理命令行引擎。Rust 核心
负责似然、参数优化、后验、模型比较、生物地理随机历史和版本化结果；新版 RASP 负责 GUI、
项目管理、可视化和报告。

v0.1 不追求 BioGeoBEARS R 函数逐函数兼容，也不参考旧版 RASP 的后台接口。所有科学能力必须
进入统一模型引擎，所有宿主接口必须通过版本化 schema，不能依赖日志文本或案例名称。

## 七、统一完成标准

每项功能只有同时满足以下条件才算完成：

- 不在核心中按 fixture 名称、区域数、tip 数或参考工具名称分支；
- 固定参数结果先于优化和性能测试；
- 涉及随机过程时使用分布级门禁或逐样本确定性门禁；
- 机器输出有版本号和 schema，失败有稳定退出码；
- 首次运行不覆盖，恢复验证任务身份；
- Windows release 中的已安装 exe 完成相同核心冒烟；
- 中文文档明确能力、限制和新版 RASP 接入边界。
