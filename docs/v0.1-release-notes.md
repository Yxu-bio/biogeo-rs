# v0.1 Windows 发布候选说明

## 定位

`biogeo-cli 0.1.0` 是面向独立命令行使用和新版 RASP 子进程接入的生物地理计算引擎。
Rust 负责似然、优化、后验、模型比较和生物地理随机历史；新版 RASP 负责 GUI、项目管理、
可视化和报告。本版本不兼容旧版 RASP 后台，也不尝试让 BioGeoBEARS R 脚本原样运行。

## 兼容范围

- 已验证平台：64 位 Windows，`x86_64-pc-windows-msvc`。
- CLI 版本：`0.1.0`；机器消费者必须同时检查 `engine-info`、schema registry 和具体格式号。
- 六个正式 preset：DEC、DEC+J、DIVALIKE、DIVALIKE+J、BAYAREALIKE、BAYAREALIKE+J。
- 输入：Newick、受支持的 NEXUS、规范范围 TSV、常见 `.data`/CSV 转换以及版本化时期输入。
- 结果：可移植分析结果、模型工作流、模型比较/平均和八种已发布生物地理随机历史目录。
- 新版 RASP 接入：v0.1 进程、schema、生命周期和项目移动边界已冻结；源码及安装版参考宿主
  均通过只读中文输入、删除源、跨目录移动、重放和重新采样。

## 已知限制

1. 尚未完成 Linux、Slurm、cgroup/affinity 和多进程作业数组测试。
2. 区域状态数是主要规模限制；高区域数任务应先运行 `analysis-plan`，并可设置可选
   `max_states` 在状态分配前提前拒绝。软件不内置当前 PC 专属的固定状态数上限。
3. 非二叉树和 `UTREE` 会显式拒绝；缺失枝长默认拒绝，只有用户明确指定统一填充值时处理。
   NEXUS 的 BOM、大小写、嵌套注释、`TRANSLATE`、带空格/转义标签及多树选择已进入门禁。
4. 单进程 BSM 已有有界线程池、分片和恢复，但内存预算不是整个进程 RSS 的硬限制。
5. CLI 不提供绘图和报告；新版 RASP 应只读取版本化机器结果，不解析英文日志。
6. 整个项目采用 `GPL-3.0-or-later`；公开再分发时需要遵守 GPL，并保留第三方许可证说明。
7. Windows 包可以保持 `local_worktree/unsigned`。代码签名和专用 CI 是可选增强，不是 GitHub
   科研软件的发布条件。

## 构建与复现

发布包由以下命令构建：

```powershell
cargo build --release --locked -p biogeo-cli
```

包内 `build-info.tsv` 记录实际 Rust/Cargo 版本、目标、构建命令、`Cargo.lock` SHA-256、引擎源码
清单 SHA-256 和 exe SHA-256；`engine-source-manifest.tsv` 逐文件记录参与引擎构建的工作区源码。
这些信息用于重建和核对同一科学实现，但当前 ZIP 时间戳未归一化，因此不承诺跨机器逐字节相同。
ZIP 条目使用标准 `/` 分隔符并限制为一个顶层包目录，避免新版 RASP 或第三方解压库误解 Windows
反斜杠；发布门禁会检查条目唯一性、根目录和关键文件。

Windows 包已升级为 `biogeo-windows-package-v3`。未签名包可以直接构建和安装；包内文件清单和
ZIP 外 SHA-256 用于校验文件一致性。只有用户主动提供签名参数或预期发布者指纹时，打包器和
安装器才检查 Authenticode。完整说明见 `docs/windows-trusted-distribution.md`。

完整候选门禁依次运行格式、Clippy、工作区测试、BioGeoBEARS golden、六 preset 随机历史
分布对照、大状态空间资源门禁、locked release 构建、安装、公开示例、真实工作流和新版 RASP
参考宿主：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File validation/checks/check-v0.1-release-candidate.ps1
```

D2-D4 首次并入后的完整运行已在 284.562 秒内通过；机器证据为
`validation/benchmark-runs/v0.1-release-candidate-20260824T041348Z-37312.tsv`。

E4 Windows PC 正式长稳持续 7,210.72 秒，完成 367 轮六模型优化和 1,503,232 条生物地理随机
历史；科学指纹零漂移，最高 working set 41,398,272 bytes。受测 EXE 和完整证据位于
`validation/benchmark-runs/windows-pc-stability-2h-20260824T084700Z/`。

E3/E4 收口后的完整 RC 门禁又在 288.82 秒内一次通过；最终 release EXE 随后用 10 轮、40,960 条
同规格随机历史复现两小时证据的科学指纹。RC 机器证据为
`validation/benchmark-runs/v0.1-release-candidate-e3e4-20260824.tsv`。

公开科研发布候选包可以直接构建和安装：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File packaging/build-windows-package.ps1

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 `
  -InstallDir C:\Tools\biogeo-cli-0.1.0
```

## 发布状态

权威机器记录是包根目录的 `release-status.tsv`。只有其中
`public_distribution_allowed=true` 且项目许可证状态已经最终确定的包才可视为公开发布候选。
当前两项已经满足：许可证为 `GPL-3.0-or-later`，公开分发标志为 `true`。这两个条件都与
Windows 代码签名无关。
