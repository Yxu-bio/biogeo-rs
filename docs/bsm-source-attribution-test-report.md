## 实现边界

本次只增加保存拟合恢复后的独立来源后处理，不重新优化、不重新抽历史，也不改变原 BSM v3 语义。似然、Q 构造、split 权重和原历史 RNG 均沿用既有实现。

支持扩散、单区域目标 founder event 及 switching；多区域 founder 目标明确报告未支持，不给出虚构落点。灭绝等事件不产生来源网络边。全零来源权重报告 `undetermined / zero_total_weight`，不使用均匀回退。

## 实际 R 对照

环境为项目隔离库中的 BioGeoBEARS 1.1.3、R 4.5.0。调用包内实际 `simulate_source_area_ana()` 和 `simulate_source_area_clado()`，不是另写一个 R 模仿算法。仅在验证条件概率时复制函数环境以记录传给 `sample()` 的 `prob`，函数体不改；额外验证这种观测在相同 R seed 下不改变函数结果。

交付示例是三区域、四末端、固定 DEC+J 参数的两时期模型。树节点年龄 2 恰为时期边界，可以明确测试边界差异。没有调用新科研数据，也不要求跨语言相同 seed 逐条一致。

|项目|结果|
|---|---:|
|固定历史数|4096|
|全部事件记录|57055|
|可分配的扩散及单目标 founder 事件|29387|
|多正权重候选抽样|13353|
|唯一正权重候选|16034|
|不适用事件|27668|
|来源输出分片|14|
|实际条件组合|36|
|R 与 Rust 条件概率最大绝对差|1.11022302462516e-16|

代表性结果如下。“选择 A 的频率”不要求恰好等于理论概率：

|事件、时期|事件数|理论 P(A)|Rust 频率|R 频率|
|---|---:|---:|---:|---:|
|AB -> ABC，年轻期|1266|0.9|0.894945|0.905213|
|AB -> ABC，较老期|2133|0.1|0.094233|0.093296|
|AB 到 C 的 founder，较老期|348|0.1|0.103448|0.094828|
|AB 到 C 的 founder，恰在边界且使用实际年轻期矩阵|128|0.9|0.820313|0.937500|

最后一行样本少，随机波动较大，未据此调 seed 或放宽阈值。所有条件及来源的完整计数保存在 `validation/r-comparison/r-distributions.tsv`，没有只保留表中几行。

预先规定的检查为：每种语言的计数与条件二项期望之差不超过 `6 * sqrt(n*p*(1-p)) + 2`；两语言计数差不超过 `6 * sqrt(2*n*p*(1-p)) + 2`。p=0 或 1 时要求精确一致。全部组合通过。该检查是可重复的回归容差，不是对两种实现数学等价性的统计证明；逐项条件概率检查同时进行。

此外，原版 R helper 对 9:1、1:9、0:1、1:0、1:1 的归一化概率分别实测，覆盖沿枝和 founder 两种情况。

## 明确保留的差异

1. **时期边界：** R helper 在恰好等于边界时选较老一期。Rust 原节点模型选较年轻一期，并带 1e-12 容差。以本例为例，原 R 分时期 helper 的 P(A) 为 0.1，而原 Rust 节点事件实际矩阵的 P(A) 为 0.9。本次不改变历史语义；非边界直接对照 R 分时期 helper，边界另传实际矩阵对照，并单独验证、记录原 R 边界行为。
2. **全零权重：** 实测 R 沿枝 helper 警告并转为等权，R founder helper 报错。Rust 不采用等权回退。全零分布通过核心测试；完整合法模拟中零速率事件不应自然发生，没有为制造该场景伪造一份科研历史。
3. **多区域 founder 目标：** 目前没有为“来源、单一落点”定义额外联合模型，明确输出不支持，而不是选取第一个区域。
