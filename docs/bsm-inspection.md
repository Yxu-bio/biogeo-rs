# 生物地理随机历史结果检查

`bsm-inspect` 用于在读取、归档、续跑或导入新版 RASP 前检查一个已经写出的生物地理随机历史
目录。它是通用格式校验器，不依赖案例名称、tip 数、区域数或生成该结果的具体 preset。

```powershell
biogeo-cli bsm-inspect --bsm-result <目录>
biogeo-cli bsm-inspect --bsm-result <目录> --deep
```

`analysis-workflow` 会在样本生成完成后自动调用同一个检查器：默认快速检查，工作流加入
`--deep` 时执行深度检查。分阶段调用 `model-bsm` 或导入外部结果时仍应显式运行本命令。

成功时 stdout 是版本化的 `biogeo-bsm-inspection-v1` 键值 TSV，`status=valid`。失败时命令返回
非零退出码；配合全局 `--error-format tsv` 可得到稳定的 `code=bsm_error` 机器错误。

## 两种级别

默认快速检查不扫描全部数据行，适合任务列表刷新和导入前预检。它验证：

- 八种已发布的 v1/v2、单目录/分片、full/compact/summary 格式；
- 根目录条目、元数据、运行状态、样本前缀和运行指纹；
- v2 区域、状态、节点、边和时期字典；
- 八张表的表头、精确字节长度和最近 checkpoint；
- 分片 manifest 的连续样本区间、累计事件数、目录名和文件长度；
- 未完成结果最多只有一个合法的活动分片。

`--deep` 在快速检查之上逐行扫描已提交的样本前缀，并验证：

- 总事件数与 `d/e/a`、`y/s/v/j` 分类计数；
- 各时期事件数量和比例；
- 状态占据时间、占据比例、稠密/稀疏表示和每条历史的总枝长；
- 节点、边、时期、状态和区域 ID 的范围及排序；
- 分支段连续性、枝长覆盖、逐事件时间、状态转移语义和完整事件链；
- v2 写出时记录的禁止状态转移、禁止端点和禁止状态占据时间诊断均为零；
- summary 的路径明细表确实只有表头。

深度检查保持流式：事件链校验同时只保留当前分支段和下一条事件，不会把大型 TSV 整体载入
内存。代价是需要顺序读取全部已提交数据，因此应在归档、传输后验收或正式导入时运行，不必在
每次 GUI 刷新时运行。

## 使用边界

检查器证明的是“目录事务完整且表间语义自洽”，不是重新执行一次似然或重新抽样历史。若要验证
拟合结果和输入仍能科学重放，应另用 `analysis-result-inspect --replay`。

v2 的 `periods.tsv` 目前记录每个时期是否有状态约束及允许状态数量，不保存完整允许状态 bitmask。
因此深度检查可以验证写出阶段的零违规诊断、ID 范围和占据表一致性，但不能脱离原分析输入独立
重建每个时期的允许状态集合。需要完全重放时，以关联的 `biogeo-analysis-result-v2` 为准。

`run_status` 为未完成、取消、超时或事件预算停止时，检查范围只覆盖 checkpoint 已提交的连续样本
前缀；未提交的写入残尾不被当成有效结果。新版 RASP 可先快速检查决定是否展示，再按用户操作或
归档策略执行深度检查。
