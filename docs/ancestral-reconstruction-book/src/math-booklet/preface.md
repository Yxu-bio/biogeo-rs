> 这本小册子不要求读者先成为数学家。目标是让你能把公式翻译成生物学问题，知道软件对什么求和、哪些量仍被固定，以及一个输出为什么不能支持过强结论。

## 小册子怎样读

全册围绕一条共同计算链展开：

\[
\text{事件率}
\longrightarrow
\text{枝上传播}
\longrightarrow
\text{节点合并}
\longrightarrow
\text{消去隐藏量}
\longrightarrow
\text{似然或后验}.
\]

| 你的目标 | 建议先读 | 暂时可以后读 |
|---|---|---|
| 看懂普通离散性状重建 | M.1–M.5 | M.7–M.10、M.14 |
| 看懂连续性状 BM/OU | M.1、M.2、M.6、M.9 | M.7、M.8 |
| 看懂 BioGeoBEARS/DEC | M.1–M.5、M.7、M.9 | M.6、M.8、M.14 |
| 看懂 PhyBEARS/SSE | M.1–M.5、M.7、M.8、M.10 | M.6、M.14 |
| 开发数值引擎 | 全读，并实际复算 M.4、M.7、M.8 | 无 |
| 了解模拟式深度学习 | M.2、M.5、M.10、M.14 | M.6–M.8 |

第一次阅读时，不必记住全部公式。每遇到一个公式，只回答五个问题：

1. 它描述节点、枝上历史，还是树的生成？
2. 竖线右边固定了哪些条件？
3. 哪些隐藏状态被求和或积分掉了？
4. 这个量是概率、似然、无量纲权重，还是每单位时间速率？
5. 它是否已经归一化为和等于 1 的后验？

## 最低先修知识

读者只需熟悉四则运算、指数和对数的直觉，并知道“矩阵是一张按行列排列的数表”。书中会直接解释条件概率、正态分布、矩阵指数、常微分方程和 softmax 在模型中承担的任务，不要求先掌握证明。

## 学完后应能做到

- 解释为什么一条枝两端状态相同，不代表枝上没有变化；
- 手算一棵三末端树的条件似然和节点后验；
- 说明 DEC 的局部消失率为何不等于整条谱系灭绝率；
- 从短时间事件表推回 SSE 的 \(E(t)\) 和 \(D(t)\) 方程；
- 解释布朗运动协方差与 OU 半衰期；
- 区分参数点估计、节点后验、随机历史和模型平均；
- 判断一个神经网络概率究竟依赖哪套训练模拟分布。
