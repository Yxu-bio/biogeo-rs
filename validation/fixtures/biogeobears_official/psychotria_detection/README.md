# Psychotria detection fixture

These files are copied without numeric changes from the BioGeoBEARS source package:

- `tree.nwk`: `inst/extdata/Psychotria_5.2.newick`
- `detections.tsv`: `inst/extdata/Psychotria_detections_v1.txt`
- `controls.tsv`: `inst/extdata/Psychotria_controls_v1.txt`

The fixture is separate from `psychotria_m4` because that pre-existing validation tree
has slightly different terminal branch lengths.
